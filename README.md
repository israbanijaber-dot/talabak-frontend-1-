# طلبك — الواجهة الأمامية (Frontend / PWA)

واجهة React حقيقية متصلة بالـ Backend عبر REST API، مبنية كـ **PWA** (تطبيق ويب قابل للتثبيت على الشاشة الرئيسية بدون متجر تطبيقات).

## التشغيل المحلي

يتطلب [Node.js](https://nodejs.org) نسخة 18 أو أحدث، **والـ Backend شغّال أولًا** (راجع `talabak-backend/README.md`).

```bash
cd talabak-frontend
npm install
cp .env.example .env
npm run dev
```

افتح `http://localhost:5173` — لازم يشتغل تسجيل الدخول والتصفح والطلب فعليًا مقابل الخادم المحلي.

## البنية

- `src/api.js` — كل الاتصالات بالـ Backend (تسجيل الدخول، المحلات، الطلبات...). أي تغيير على شكل الـ API يصير هون فقط.
- `src/App.jsx` — كل شاشات التطبيق الأربعة (عميل، صاحب محل، مندوب، إدارة) بنفس التصميم والهوية البصرية الأصلية، لكنها الآن تجلب بياناتها من `api.js` بدل بيانات محلية وهمية.
- `vite.config.js` — إعداد الـ PWA (اسم التطبيق، الأيقونة، العمل شبه-أوفلاين للواجهة).
- `public/icon-192.png` / `icon-512.png` — أيقونة مبدئية بسيطة بألوان الهوية البصرية. **يُنصح باستبدالها بشعار احترافي حقيقي قبل الإطلاق الفعلي.**

## البناء للنشر (Production Build)

```bash
npm run build
```

ينتج مجلد `dist/` — هذا هو الموقع الجاهز للنشر (ملفات ثابتة HTML/CSS/JS).

## النشر (Deployment) على استضافة مجانية

الأسهل: [Vercel](https://vercel.com) أو [Netlify](https://netlify.com):
1. ارفع مجلد `talabak-frontend` كمستودع على GitHub.
2. من Vercel: New Project → اختر المستودع → Framework: Vite (يُكتشف تلقائيًا).
3. أضف متغيّر البيئة `VITE_API_URL` بقيمة رابط الـ Backend الحقيقي بعد رفعه (مثلاً `https://talabak-backend.onrender.com/api`).
4. Deploy — بيصير عندك رابط دائم مثل `https://talabak-aqraba.vercel.app` (وتقدر تربط دومين مخصص لاحقًا مجانًا أو برسوم بسيطة).

## كيف "يتنزّل" عند الناس (بدون متجر تطبيقات)

بعد ما يصير عندك الرابط: افتحه على الموبايل → من قائمة المتصفح اختر **"إضافة إلى الشاشة الرئيسية" / Add to Home Screen** → بتظهر أيقونة طلبك متل أي تطبيق عادي.
